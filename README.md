# React Quest · Semana 2

Juego interactivo para practicar props, `useState` +
eventos, renderizado condicional, `useEffect` y custom hooks a través de
7 misiones, con un panel de errores en criollo para cuando el código no
compila.

## Cómo correrlo

Requiere Node 20.19+ o 22.12+.

```bash
cd clase11_react_semana2
npm install
npm run dev
```

Abrí la URL que muestra la terminal (por defecto
`http://localhost:5173`).

## Cómo jugar

Editá los archivos dentro de `src/misiones/` — cada uno tiene la
consigna de una misión. Guardá y mirá cómo se tildan los objetivos solos
en el panel de la derecha. Si te trabás, pedí pistas o revelá la
solución de referencia.

## Progreso

El progreso se guarda en el `localStorage` del navegador. El botón
"↺ Reiniciar progreso" del mapa de misiones lo borra por completo.
